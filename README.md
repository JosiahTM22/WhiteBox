**Welcome to WhiteBox**

This is a project created by Josiah Mirabella for GAME 310 - Digital Game Design

The game is a 3D puzzle-platformer inspired by games such as Portal and Talos Principle



**Note for Playtesters**

The content currently in the project file is more or less the tutorial

I expect players to be able to understand the mechanics introduced and pass the tri-color door

I would like to know what you think about the current difficulty

I would also like you to try to softlock yourself

When you open the project, please switch the level to TitleScreen and start from there



**Controls**

WASD - Move around

Mouse - Look around

P - Pause/Unpause the game

E - Interact with doors



There are also several developer commands

ctrl+1 - Turn on Third Eye filter

ctrl+2 - Turn off Third Eye filter

ctrl+3 - Give key

ctrl+4 - Take key (for some reason)

ctrl+5 - Heal 20 HP

ctrl+6 - Damage 20 HP
